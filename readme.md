# 부대 달력

병사가 자기 달력 하나에서 부대 일정을 보고, 휴가·외박·외출을 신청하고, 체육 시설을 예약하는 웹앱입니다. 부대 AI 동아리에서 바이브코딩으로 만듭니다.

> 현재 상태: 개발 시작 전입니다 (Phase 0 준비 중). 아직 실행할 수 있는 앱은 없습니다. 진행 상황은 [current_status.md](current_status.md)를 보세요.

## 무엇을 해결하나요

| 지금의 불편 | 이 앱에서는 |
| --- | --- |
| 부대 일정을 게시판이나 구두로 전달받는다 | 간부가 등록하면 공휴일처럼 내 달력에 뜬다 |
| 남은 휴가 일수를 직접 계산한다 | 종류별 잔여 일수가 자동으로 계산된다 |
| 그 날 휴가 자리가 남았는지 물어봐야 안다 | 정원이 찬 날짜가 회색 "마감"으로 보인다 |
| 시설이 비었는지 가 봐야 안다 | 빈 시간대를 보고 바로 예약을 신청한다 |

## 핵심 기능

1. **개인 달력과 부대 일정**: 내 일정을 적고, 간부가 등록한 부대 일정을 함께 봅니다.
2. **휴가·외박·외출 신청과 출타율 제한**: 신청하면 바로 자리를 차지하고, 출타율만큼 인원이 차면 그 날짜는 신청이 막힙니다.
3. **시설 예약**: 풋살장·운동장과 체육관의 빈 시간대를 신청하고 간부가 승인합니다.

이 앱의 휴가 신청은 출타율 관리를 위한 것입니다. 정식 휴가 승인은 기존 부대 절차대로 따로 받아야 합니다.

## 실행 방법

개발 도구는 아직 확정하지 않았고, 지금은 설치 없이 동작하는 HTML+JS로 만들고 있습니다. PC에 Python이 있으면 다음처럼 실행합니다.

```
cd "프로젝트 폴더 경로"
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 끝낼 때는 터미널에서 `Ctrl + C`를 누릅니다.

연습용 가상 인원은 이름과 개인 코드로 들어옵니다 (Phase 0~4 전용). 자주 쓰는 인원은 다음과 같고, 전체 목록은 들어오기 화면 아래 "연습용 가상 인원 코드 보기"에 있습니다.

| 역할 | 이름 | 소속 | 개인 코드 |
| --- | --- | --- | --- |
| 간부 | 백지훈 | 본부 | YCM2Y5 |
| 간부 | 남궁현 | 본부 | BQEPH8 |
| 병사 | 김하늘 | 1중대 | CZUTP6 |
| 병사 | 이바다 | 2중대 | X4DVGP |

코드는 소문자로 넣어도 됩니다. 같은 이름으로 5회 연속 틀리면 10분간 막힙니다. 연습 중에 바로 풀고 싶으면 브라우저의 사이트 데이터를 지우면 됩니다.

단계별로 필요한 환경은 다음과 같습니다.

| 단계 | 필요한 것 | 데이터 |
| --- | --- | --- |
| Phase 0~4 | 브라우저가 있는 PC 또는 휴대폰 | 코드 안의 가상 데이터. 새로고침하면 처음 상태로 돌아갑니다 |
| Phase 5 | 인터넷이 되는 환경, Supabase 프로젝트 | Supabase에 저장되는 가상 데이터 |

Phase 5부터는 Supabase 주소와 키를 환경 변수 파일에 넣어야 합니다. 이 파일은 저장소에 올리지 않습니다.

## 사용 방법

아래는 완성되었을 때의 사용 흐름입니다.

### 처음 들어오기 (병사)

1. 전입하면 간부가 나를 인원으로 추가하고, 나만의 개인 코드(영문·숫자 6자리)를 직접 알려 줍니다.
2. 앱 첫 화면에서 이름과 개인 코드를 입력합니다. 같은 휴대폰에서는 다음부터 바로 들어가집니다.
3. 코드를 잊으면 간부에게 다시 발급받습니다. 이전 코드는 더 이상 쓸 수 없습니다.

### 달력 보기

- 달력 탭에서 월간 달력을 봅니다. 날짜를 누르면 그날의 일정이 아래에 나옵니다.
- 개인 일정(근무, 생일 등)은 직접 추가합니다. 나만 볼 수 있습니다.
- 부대 일정은 간부가 등록하면 자동으로 보입니다.

### 휴가·외박·외출 신청하기

1. 신청 탭의 휴가 영역에서 받은 휴가 일수를 요청합니다 (종류, 일수, 사유). 간부가 승인하면 남은 일수에 반영됩니다.
2. 신청할 종류(휴가, 외박, 외출)를 고릅니다.
3. 달력에서 날짜를 고릅니다. 날짜마다 남은 자리 수가 보이고, 회색 "마감" 날짜는 고를 수 없습니다.
4. 휴가라면 어떤 종류의 휴가를 며칠씩 쓸지 고릅니다 (예: 연가 3일 + 포상휴가 2일).
5. 신청을 누르면 바로 등록됩니다.

알아 둘 점:

- 오늘부터 한 달 이내의 날짜까지만 신청할 수 있습니다.
- 날짜를 바꾸려면 취소한 뒤 다시 신청합니다. 취소하면 자리와 일수가 되돌아옵니다.

### 시설 예약하기

1. 신청 탭에서 아래쪽 시설 영역으로 내려가 시설과 날짜를 고릅니다.
2. 빈 시간대를 고릅니다. 1시간 단위이며 한 번에 최대 2시간입니다.
3. 신청하면 "대기" 상태가 되고, 간부가 승인하면 내 달력에 표시됩니다.

먼저 신청한 사람만 받습니다. 누가 신청한 시간대는 회색 "신청 중"으로 보입니다.

### 간부가 하는 일

간부로 로그인하면 같은 탭 안에 간부용 영역이 추가로 보입니다.

| 위치 | 할 수 있는 일 |
| --- | --- |
| 달력 탭 | 부대 일정 추가, 수정, 삭제. 훈련은 "훈련"으로만 표시됩니다 |
| 신청 탭 - 휴가 영역 | 기본 출타율과 기간별 출타율 입력, 날짜별 출타 인원과 신청자 명단 확인, 받은 휴가 일수 승인 |
| 신청 탭 - 시설 영역 | 예약 신청 승인, 반려 |
| 사용자 메뉴 | 인원 추가·개인 코드 발급, 코드 다시 발급 |

하루 정원은 "부대 전체 병사 수 × 출타율"이며 소수점은 버립니다. 예를 들어 병사 43명에 출타율 20%이면 하루 8명입니다.

## 이 앱에 없는 것

공개 회원가입, 결제, 알림, 관리자 페이지는 만들지 않습니다. 휴가의 정식 승인도 다루지 않습니다.

## 주의 사항

- 개발과 시연에는 가상의 이름과 일정만 씁니다. 실제 병사 정보를 인터넷의 클라우드에 올리지 않습니다.
- 비밀로 분류되는 내용은 부대 일정에 입력하지 않습니다.
- 군번, 연락처, 주민등록번호는 받지 않습니다.
